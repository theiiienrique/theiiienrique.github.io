# User story template

## About this sample

I created this template while contributing to The Good Docs Project. It is paired with the [user story guide](user-story-guide.md) and shows how I design reusable documentation assets that help cross-functional teams write clear, consistent user stories.

## Template

If you need more information about how to fill in this template, read the accompanying [user story guide](user-story-guide.md).

## Title

Write a short, descriptive title for the user story. For example, `Add to library button`.

## User story

Write a short description of the feature from the user’s perspective.

> As a user persona, I want to do some task so that I can achieve some goal.

## Acceptance criteria

List the outcomes the user should observe when interacting with the feature. All statements must be true to consider the user story complete.

- `Observable outcome 1`
- `Observable outcome 2`
- `Observable outcome n`

## Optional: Priority

Label the priority level for this user story.

You can designate priority levels using tags such as `Critical`, `High`, `Medium`, and `Low`.

## Optional: Story points

Use story points to estimate the time and effort required to complete this user story. Use relative sizing, such as selecting a number from the Fibonacci sequence or shirt size, rather than absolute sizing, such as measuring in days or weeks.
